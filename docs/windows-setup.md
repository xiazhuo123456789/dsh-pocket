# 电脑端配置

**只有一步。** 你不需要安装任何 DSH Pocket 组件、插件或服务。

## 前提

- DeepSeek Harness Desktop 已安装并能正常启动
- 「远程控制」能力可用（本应用在 `0.2.0-rc.2` 运行时 + `@linxin666/dsh-remote-web-ui`
  插件上验证；其他版本请以实际界面为准）

## 生成配对链接

1. 打开 DeepSeek Harness Desktop
2. 进入**设置 → 远程控制**（或侧边栏的远程入口）
3. 确认隧道状态是「运行中」；界面会显示一个 `https://<随机词>.trycloudflare.com` 地址
4. 点「生成配对链接」或直接扫界面上的二维码

配对链接形如（下例中的主机名和 token 均为示意，不是真实可用的链接）：

```
https://example-words-here.trycloudflare.com/pair-accept?pair=<一次性token>
```

**这个链接等同于一次性的登录凭据。** 不要发到群里、不要贴进公开 issue。

## 在手机上配对

两种方式：

- **粘贴链接** — 把上面整段复制到手机，粘进 DSH Pocket 的输入框
- **扫码** — 把电脑上的二维码截图发到手机（微信/QQ/数据线都行），在应用里点
  「从相册选择二维码图片」

配对成功后应用会自动连接并列出电脑上的会话。

## 管理已配对设备

电脑端**设置 → 远程控制**里能看到已配对设备列表，可以单独撤销。

撤销后该手机立即失去全部远程能力。手机端的「断开并清除」只删除本机凭据，
**不会**撤销电脑侧的授权——彻底撤销必须在这块面板里做。

## 关于隧道地址会变

默认使用 Cloudflare quick tunnel，主机名在每次 DeepSeek Harness 启动时重新分配。
所以：

- 重启电脑或重启 Harness 之后，旧链接失效，需要用新链接重新配对
- 手机端会显示连接错误，而不是静默失败

如果你想要固定地址，需要在远程控制面板里配置 named tunnel（需要 Cloudflare 账号和
一个域名）。那是电脑端配置，不影响手机应用。

## 局域网直连

如果手机和电脑在同一 Wi-Fi，并且远程控制面板开启了「允许局域网访问」，配对链接会
是 `http://192.168.x.x:<port>/pair-accept?...`。应用支持明文 HTTP（见
`network_security_config.xml` 里的说明），因为这是你自己的局域网。

局域网直连比隧道快得多，推荐在家里/办公室使用。缺点是离开这个 Wi-Fi 就用不了。

## 不需要做的事

- ❌ 不需要在电脑上装 DSH Pocket 的 exe / 服务 / 计划任务
- ❌ 不需要改 DeepSeek Harness 的安装文件
- ❌ 不需要把 API Key、Harness 内部令牌或 `.credentials.yaml` 交给手机
- ❌ 不需要关闭认证或防火墙

如果你看到某份教程要求做上面任何一条，那份教程是错的。

## 排障

见 [troubleshooting.md](troubleshooting.md)。最常见的问题：

| 现象 | 原因 |
| --- | --- |
| 手机提示「无法识别配对链接」 | 链接不完整，或复制时漏了 `?pair=` 部分 |
| 配对成功但立刻断线 | 隧道地址已变（Harness 重启过） |
| 所有请求返回 403 | 设备已被撤销，需要重新配对 |
| 局域网地址连不上 | Windows 防火墙拦了，或不在同一网段 |
